[The Worst App Idea Ever Pitched](https://make.fun/bounty/u-plucky-sparrow-67-the-worst-app-idea-ever-pitched-a0396b23).

**LaundryLive** streams your washing machine spin cycle to your in-laws in
real time, with slow-motion replays of every sock that escapes and a weekly
leaderboard ranking your load sizes against theirs.

## Run

```sh
python3 main.py
```

The program reads `MAKEFUN_OUTPUT_DIR` (default `/output`) and writes
`entry.txt` containing exactly the one-sentence pitch above — 198 characters,
no trailing newline.
